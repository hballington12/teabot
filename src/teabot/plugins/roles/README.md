# roles

- A first-party plugin: a post with a button for each role, which members press to take the role, and press again to give it back.
- What it does, its commands and who can use them: https://teabot-dev.github.io/teabot/use/plugins/roles/
- External connections: none.
- Tests: `tests/plugins/roles/`, through `teabot.testing`.
