# giveaways

- A first-party plugin: members enter giveaways, and winners are drawn when time is up.
- What it does, its commands, settings and who can use them: https://teabot-dev.github.io/teabot/use/plugins/giveaways/
- External connections: none.
- Tests: `tests/plugins/giveaways/`, through `teabot.testing`.
