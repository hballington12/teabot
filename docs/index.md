## Why Teabot?

<div class="grid cards teabot-features" markdown>

-   :lucide-plug-zap:{ .teabot-badge }

    **Easy to use**

    Connect it to any MCP client, such as Claude Code, in a few minutes, and let it handle your Discord management the modern way.

-   :lucide-sliders-horizontal:{ .teabot-badge }

    **Freely customisable**

    Make Teabot work for you. Pick the plugins your server needs, and leave paywalled bot features behind.

-   :lucide-infinity:{ .teabot-badge }

    **Endless possibilities**

    The plugin SDK wires your own plugins straight into Teabot, so you skip the boring parts and get straight to making your server what you want it to be.

-   :lucide-shield-check:{ .teabot-badge }

    **Safe by design**

    Set the permissions and Teabot enforces them. You choose who does what, and destructive changes always await confirmation.
