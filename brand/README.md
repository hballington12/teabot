# brand

- `teabot.png`: the README's logo, 512 by 512 with a transparent background, shown at the top of the README. It is made from `teabot_logo.png` by `scripts/docs/brand.py`.
- `teabot_small.png`, `teabot_medium.png`, `teabot_large.png`: the three mascots, 1182 by 1182, for guild admins, self-hosters and plugin developers. `scripts/docs/brand.py` makes the docs' copies from them.
- `teabot_logo.png`: the logo, a simplified teapot, 1174 by 1174, used where it shows large: the README and the docs' home page.
- `teabot_favicon.png`: the logo drawn for small sizes, 754 by 754, used for the browser tab and the docs' header.
